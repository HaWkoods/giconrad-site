# 擬コンラット — 数学ノート横断索引

[公開検索サイト](https://hawkoods.github.io/giconrad-site/)では、数学ノート157件を番号順・分野別・概念・手法別に検索できます。各タイトルから概要・推奨先行ノート・次に読むノートの案内ページへ進めます。

## PDFへのリンクと公開範囲

検索結果とノート個別ページの「PDFを開く（要閲覧権限）」は、管理用の **Private GitHubリポジトリ** 内のPDFを指しています。

- **リンク先のURL、リポジトリ名、PDFファイルパスは公開されます。**
- **PDF本文・pLaTeX原稿・内部校閲資料は公開用リポジトリには置いていません。**
- PDFを開くには、GitHubへログインし、管理用Privateリポジトリに対する閲覧権限を持っている必要があります。
- GitHub Pages自体には閲覧認証機能を付けていません。アクセス制御はGitHub側のPrivateリポジトリ設定が担います。
- アクセストークンなどの認証情報は公開サイトに保存しません。

この公開用リポジトリにはHTML、CSS、JavaScript、ノート案内用のメタデータとPrivate PDFへのURLだけを置いています。
