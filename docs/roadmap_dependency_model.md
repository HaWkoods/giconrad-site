# 擬コンラット：定理の放射状学習マップ用依存関係

この文書はマップ描画前の**データ設計**を定める。表示のために論理的前提を推測・捏造しない。

## 1. ノード

- `note:AA.BBB`: 公開数学ノートそのもの（157件）。一冊のノートと一個の定理は一般に一致しない。
- `concept:slug`: 定義、補題、基本手法、定理などの**概念的な学習事項**。現在の登録は17件で、全数学の概念の網羅ではない。
- 将来は `theorem:...` という独立した定理ノードを追加する。ノートのどの節・定理環境にその定理があるか対応付け、実際の証明単位を区別する。
- 別分野に属する概念は同一ノードを共有する（画面上で複製して別IDを振らない）。

## 2. 辺の方向と意味

全辺は **前提／推奨元 → 到達したい対象** の向きで記録する。

| 属性 | 値 | 意味 |
| --- | --- | --- |
| `relation` | `concept_prerequisite` | 原稿の該当する証明・導入で利用する概念 |
| `relation` | `recommended_reading` | 既存索引の「先に読むとよいノート」（**論理的必然性を意味しない**） |
| `strength` | `strong` | **根拠となる特定の証明・導入**の理解に直接必要な概念。あらゆる別証明にも必須とは主張しない |
| `strength` | `weak` | 関連知識として有用だが、その証明の直接の論理的前提ではない |
| `strength` | `unassessed` | 未分類。**弱い前提と同義ではない** |
| `review` | `source_inspected` | 引用した原稿・節の記述を実際に調べた。全証明を査読済みとは意味しない |
| `review` | `catalogue_only` | 分類索引から機械的に取り込んだだけで、前提の強度は未検証 |

強い関係には原稿ファイルと節を `evidence` に明示する。既存の202件の推奨読書関係を一律に強い辺や弱い辺へは変換しない。

例：`53.040`（Hopf–Rinow）の証明はRiemann距離と測地線、指数写像、有限次元の閉球のコンパクト性を利用するが、`54.050` のTychonoff定理自体を使わない。従来の `54.050 → 53.040` は、原稿確認により「弱い推奨読書関係」に分類した。単に「コンパクト性を使う」ことと「Tychonoffの定理を使う」ことは異なる。

## 3. 放射状表示の方針（実装前仕様）

中央に目標定理／目標ノートを置き、外周に直接前提を表示する。ノードのクリックで一段ずつ展開し、循環を回避する。複数の前提が同時に必要ならAND結合として表示する。将来、代替の証明経路を登録できる場合はORグループを別データとして定義する（現在は未実装）。

描画時には概念とノートの形状を変える。強い辺は**実線**、弱い辺は**点線**、未分類は**薄い破線と「未確認」ラベル**とする。未分類を黙って弱い前提として処理してはならない。枝を広げたときに画面に入り切らない場合はパン・ズーム／段階的展開を検討する。

同じノート内の定義・補題の関係と、独立したノートを読む推奨順は別物である。学習順の自動生成は「既存の推奨順」から可能だが、**形式的な証明依存グラフ**として公開するには定理単位で引用箇所・仮定・使用補題を監査する。
