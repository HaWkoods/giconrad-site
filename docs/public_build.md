# 擬コンラット：公開ノートと自動ビルド

`giconrad-site` は公開検索サイトと、公開対象として選んだ数学ノートの pLaTeX 原稿・PDF を管理する。

## 公開するもの

- `public_notes/` に追加された pLaTeX 原稿・PDF は公開される。
- `data/public_pdf_links.json` に登録したノートだけ、検索サイトに公開PDF・ソースのリンクを表示する。
- それ以外のノートは引き続き非公開の管理用リポジトリに置き、従来の認証付きリンクを使用する。
- Google Driveの参考文献、未公開原稿、APIトークン、内部査読資料は転記しない。

## 自動ビルドの仕組み

`.github/workflows/build_public_notes.yml` は `public_notes/**/*.tex` の変更、ビルドスクリプトの変更、手動実行で動く。
通常のpushでは変更された `.tex` ファイルだけをビルドする。ワークフロー変更時と手動 `all` 指定時は全公開ノートを再ビルドする。
各 `.tex` に対して pLaTeX 2 回と dvipdfmx 1 回を実行し、生成PDFに変更があれば、この公開リポジトリの `main` にコミットする。
元の Privateリポジトリは、ビルドの中で checkout しない。

手動実行は **Actions → Build public pLaTeX notes → Run workflow** を開き、`note=97.120`（単独）または `all` を指定する。

## 公開前の注意

- 著作権上の転載、個人情報、秘密情報、未公開の参考文献、数学的な校閲状態を確認してから原稿を公開する。
- 公開するとGitの履歴にも残るため、後からファイルを削除するだけでは秘密状態に戻せない。
- 97シリーズ第1期6冊は「初稿・数学的校閲中」として公開する。公開は数学的な最終承認を意味しない。
