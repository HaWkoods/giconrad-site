上記は**学習順の原稿照合による第一次査読**であり、数学的な証明依存関係を完全に認定したものではない。「強い前提」に確定するには、対象定理と先行結果の対応、使用する仮定、および引用位置を別途定理単位で検査する。既存グラフの `strong` / `weak` 表示への一括転写は行わない。

## 原稿照合により整理した重要な違い

- **53.040と54.050**：Hopf–Rinowの証明は距離完備性、測地線と有限次元コンパクト性を使うが、Tychonoffの定理自体は前提として使わない。よって弱い補助的関係。
- **28.010と60.010**：条件付き期待値の存在証明ではRadon–Nikodymの定理を明示的に引用する。これは中心的な依存関係。
- **47.010と60.050**：SDEの存在証明はPicard反復の階乗型評価で進む。原稿は有限区間で一度に縮小写像を作る方法ではないと明記している。Banach不動点定理の先行ノートは補助的な関係に留める。
- **55.030**：自由積の定義と基本性質をその原稿内で扱っているため、自由対象の一般論（18.020）は直接の必須関係とは言えない。むしろ基本群を扱う55.020の登録漏れが重要である。
- **54.060**：Urysohnの補題は正規空間について証明され、Tychonoffの定理自体を使わない。従来の54.050との関係は補助知識。

4. 現行の「強い前提」「弱い前提」への反映は、この追加査読後に行う。
