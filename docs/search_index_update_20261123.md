既存索引からの推奨関係132件は、「前提・章構成が対応する」という一般的な説明しかなく、具体的な節・定理が特定されていなかったため、数学的に推論可能から**要確認・関連度低**へ修正した。

「確認済み」は関連する本文の節・使用対象を直接照合したという意味であり、定理や証明そのものの数学的完全性を保証しない。
「数学的に推論可能」は原稿構造監査などをもとに理論的接続・学習上の関連を判断したもので、個々の証明への依存を検証したものではない。
既存の推奨読書順のうち、監査で根拠が不足するとされた11件は `relations.json` の候補から除外したが、歴史的な未判定の読書経路として元の `roadmap_graph.json` には残す。ロードマップの未判定辺は数学的必須前提として解釈してはならない。

## 調査の根拠と限界

- 150本について既存の `docs/revision_audit_data/all_150_structural_20261122.json` の原稿構造検査を利用。これは証明の正しさの査読ではない。
- 新規に扱った10本について主としてpLaTeX原稿の題名・節・定理見出しを直接確認。全文の各論証の検証は未実施。
- 一部概要は既存の `summary_basis=planned_goal` に由来する。学習目標と原稿の実際の証明結果を混同しない。
- 概念IDの英名は既存の英語タグ・選定した数学用語から構成。全217項目の標準英名の人手による査定は今後必要。
- 詳細概要と主結果は節構成由来の暫定索引が多い。本文にない定理が実証されたと読み替えない。
- ファイルのGitHub上の存在と、数学的に誤りがないことは別である。

- 登録ノート160件と個別案内160件のID一致。
- 概念217件、関連性228件の参照先が全て存在。

## 今後の更新手順

1. 管理用GitHubの `notes/` を列挙し、追加・移動・削除を差分検出する。
2. ノートIDは維持し、新規IDだけ手動割当てする。正式題名と本文の節を確認する。
3. `data/notes.json` の内容索引と `data/concepts.json` の別名・IDを更新する。
4. `data/relations.json` へ新しいノートとの根拠付き関係を追加し、要確認を未検証として残す。
5. `python3 scripts/validate_math_index.py` と従来のロードマップ検証を実行する。
6. PDF・TeXの公開は別の許諾判断とし、`data/public_pdf_links.json` に許可IDを追加するまでは同期対象としない。
