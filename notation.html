共通記号・記法一覧

擬コンラットに収録する数学ノートで用いる主要な記号をまとめる。全ノートの意味を無条件に統一する一覧ではない。「規約」は明示された共通の読み方、「分野」は対象・前提によって意味が定まる記法、「要確認」はノート間で用法が変わるか、全冊の統一確認が済んでいない記法である。

各ノートの冒頭や初出箇所に記された定義・仮定が優先される。この一覧が、個別ノートの定義を省く理由になることはない。記号の意味が定まらない場合は推測せず、該当するノートの本文を確認する。

基礎・集合・写像

記号意味・定義適用上の注意ノート例
ℕ自然数全体。0 を含めるかはノート間で未統一であり、現段階では一律に固定しない。使用するノートで {0,1,2,…} または {1,2,…} と明示する。要確認—
ℕ₀{0,1,2,…}。0 を含む非負整数全体。多重指数など、0 を含むことが必要な場合に用いる。規約13.030
A ⊆ BA の全ての元が B に属する。A = B を許す。等号の有無を明確にする場合はこの記号を使う。規約54.010
A ⊊ BA ⊆ B かつ A ≠ B（真包含）。⊊ と ⊂ を混同しない。規約15.010
A ⊂ B包含記号。既存原稿では等号を許す用法があるが、全冊での統一は未確認。改訂時は可能な限り ⊆ または ⊊ に置き換え、ノート内でも説明する。要確認54.020
𝒫(X)集合 X の冪集合、すなわち X の部分集合全体。値域・順序の意味では使用しない。規約54.010
f⁻¹(A)f : X → Y と A ⊆ Y に対し、{x ∈ X : f(x) ∈ A}。f が全単射でなくても定義される。逆写像とは区別する。規約54.010
1_A, 𝟙_A集合 A の指示関数。A 上で 1、A の外で 0。1_A の定義域は文脈の全空間とする。分野28.010
A°位相空間の部分集合 A の内部。A に含まれる最大の開集合。分野54.010
A̅位相空間の部分集合 A の閉包。閉球の記号との混同に注意する。分野54.010

位相・関数空間・解析

記号意味・定義適用上の注意ノート例
B_X(x,r)距離空間 (X,d) の開球 {y ∈ X : d(x,y) < r}（r > 0）。B(x,r) は空間の添字を省略した記法。既存原稿の各用例は要点検。分野46.050
閉球{y ∈ X : d(x,y) ≤ r}（r ≥ 0）。一般の距離空間では開球の閉包と一致するとは限らない。分野46.050
C(X;𝕂)X 上の連続な 𝕂 値関数全体（𝕂 = ℝ または ℂ）。連続性の位相と値域はノート内で指定する。分野46.010
supp f関数 f が 0 でない点の集合の閉包（台）。測度論の本質的台とは区別する。分野22.030
C_c(X)X 上のコンパクトな台をもつ連続関数全体。実数値か複素数値かは、そのノートの係数体の約束による。分野22.030
C_c^∞(Ω)開集合 Ω 上の滑らかな関数で、台が Ω 内のコンパクト集合であるもの全体。試験関数空間。境界上まで台が達する関数は含めない。分野35.020
Lᵖ(μ)μ に関して p 乗可積分な可測関数を、μ ほとんど至る所の一致で同一視した空間（1 ≤ p < ∞）。L∞ は本質的上限を用いて別途定義する。分野28.010
‖f‖_{Lᵖ}(∫ |f|ᵖ dμ)^{1/p}（1 ≤ p < ∞）。同値類に対して定義されるノルム。分野28.010
a.e. / 概至る所指定した測度について、零集合を除いて成り立つこと。「どの測度に関して」を明記する。分野28.010
𝓑(X)位相空間 X の開集合族が生成する Borel σ-加法族。𝓑(X,Y)（有界線形作用素全体）と異なる。分野28.020
𝓛ⁿℝⁿ の Lebesgue 可測集合全体の σ-加法族。Borel σ-加法族 𝓑ⁿ と区別する。分野28.020
σ(X,X*)X 上の連続双対 X* による弱位相。実ノルム空間・実 Banach 空間の文脈。分野46.060
σ(X*,X)X* 上の評価写像 f ↦ f(x)（x ∈ X）が定める弱*位相。X* 自身の弱位相 σ(X*,X**) とは通常異なる。分野46.060
x^α, ∂^α多重指数 α=(α₁,…,α_d) ∈ ℕ₀ᵈ に対し、x^α=∏xⱼ^{αⱼ}、∂^α=∂₁^{α₁}⋯∂_d^{α_d}。偏微分の存在階数は個別の命題の仮定による。分野42.020

線形・作用素・双対

記号意味・定義適用上の注意ノート例
E*ノルム空間 E の有界線形汎関数全体からなる連続双対空間。位相のない線形空間の代数的双対とは区別。分野46.040
E**(E*)*。連続双対 E* の連続双対。x ∈ E を評価汎関数 f ↦ f(x) と同一視する標準埋め込みがある。分野46.060
‖f‖_{E*}sup{|f(x)| : ‖x‖_E ≤ 1}。有界線形汎関数 f に対する作用素ノルム。分野46.040
𝓑(E,F)ノルム空間 E → F の有界線形作用素全体。Borel σ-加法族を表す 𝓑(X) とは別記号。分野46.050
‖T‖sup{‖Tx‖_F : ‖x‖_E ≤ 1}（T : E → F は有界線形）。空間固有のノルムに依存する。分野47.020
𝓚(E,F)E → F のコンパクト線形作用素全体。作用素は有界線形である。分野47.020
⟨x,y⟩内積または双対ペアリング。複素内積がどちらの変数で線形か、双対評価かは全冊で未統一。各ノートで定める。要確認46.030
M_{m,n}(R)環 R に係数をもつ m 行 n 列の行列全体。積が定義される行列の型を区別する。分野15.010
GLₙ(R)R 上の n 次可逆正方行列全体の群。体以外の環でも定義する。分野15.010

代数・圏・幾何

記号意味・定義適用上の注意ノート例
R×, K×環・体の単元全体からなる乗法群。体の場合は K \ {0} と一致する。分野12.050
(a,b), (d)環 R のイデアル Ra+Rb および Rd。数論で (a,b) を最大公約数として使う表記とは区別する。分野15.010
𝔽ₚ, 𝔽_q𝔽ₚ=ℤ/pℤ（p は素数）。𝔽_q は q 元の有限体（q は素数冪）。抽象的な有限体の同型類は一意だが、元の同一視は指定が必要。分野12.010
[L:K]体の拡大 L/K の次数 dim_K L。無限次拡大にも基数として定義できる場合がある。分野12.010
Spec(A)可換環 A の素イデアル全体。通常は Zariski 位相を備える空間として扱う。分野13.020
V(I)イデアル I を含む素イデアル全体。Spec(A) の閉部分集合。V(I)={𝔭 ∈ Spec(A) : I ⊆ 𝔭}。分野13.020
Hom_C(A,B)圏 C の対象 A から B への射の集合。C が小圏でない場合は集合の大きさの取り扱いに注意。分野18.010

Cᵒᵖ圏 C の反対圏。対象は同じで射の向きを逆にする。合成の順番も反転する。分野18.010

測度・確率

記号意味・定義適用上の注意ノート例
ν ≪ μν が μ に関して絶対連続：μ(A)=0 ⇒ ν(A)=0。数論の Vinogradov 記号 ≪ と意味が違う。分野28.010
dν/dμRadon–Nikodym 密度：ν(A)=∫_A f dμ を満たす f（μ-a.e. で一意）。適切な絶対連続性・有限性などを仮定して用いる。分野28.010
σ-有限空間が測度有限の可測集合の可算和で覆われること。対象となる測度を特定する。分野28.010
P(A), E[X]確率空間 (Ω,𝓕,P) における確率 P(A) と期待値 ∫_Ω X dP。期待値を取るための可積分性を確認する。分野60.020
Cov(X,Y)E[(X−E[X])(Y−E[Y])]。二次可積分性など、存在を保証する仮定が必要。分野60.020

記号意味・定義適用上の注意ノート例

≪測度では絶対連続、解析的整数論では上界 O(·) に相当する記号として使うことがある。左右の対象・分野で判定し、初出で必ず明示する。要確認28.010
∂偏微分記号、境界作用素、連結準同型など。分野・次数で意味が異なるため、適用対象と定義域・値域を確認。要確認18.050

運用上の約束

この一覧は主要記号の初版（55項目）であり、全160冊の原稿からすべての記号を網羅的に抽出したものではない。今後の査読では、定理の仮定、量化、記号の定義域・値域に関わる表記を優先して追記する。「要確認」の記号は、定義が確定したノートごとに参照例を増やしていく。

共通の運用方針は 記号と表記の方針 に記録されている。このページはその方針とは別に、記号の実際の意味を引くための中心的な参照先である。
